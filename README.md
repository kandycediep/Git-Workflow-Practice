# Git-Workflow-Practice

Welcome! This repository is a hands-on practice space for learning the Git/GitHub workflow we use everyday.

Instead of just reading about `clone`, `branch`, `commit`, `push`, and opening a Pull Request (PR), you'll actually perform each step yourself in a low-stakes practice repository.

## What You'll Practice

- Cloning a repository to your machine
- Creating a branch
- Making a small code change
- Staging and committing your changes
- Pushing your branch to GitHub
- Opening a PR

## Get Started

Open **Git-Workflow-Practice.md** and follow the instructions step by step.

**Estimated Time:** 20–30 minutes

## Why This Exists

During my internship, a challenge that I came across involved understanding the Git workflow. I spent the first few days just trying to learn the basic commands before I could contribute to my team's codebase. I created this repository so new interns can practice that same workflow in a low-stakes environment, fixing a small bug from start to finish before working on a real project.
